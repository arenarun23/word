# 끝말잇기 놀이터
초등 저학년용 끝말잇기 웹앱 (정적 파일, 서버·API 키 불필요). `index.html` 하나로 동작하고 `extra.txt` 는 보조 사전(없어도 동작).
- 입력: 키보드 / 🎙️ 말하기(Web Speech API) / ✍️ 손글씨(구글 입력도구 필기 인식, 한자 찾기 앱과 동일 방식) / 💡 힌트 버튼
- 두음법칙: 끝 글자가 `리·녀·라…` 이면 `이·여·나…` 로 시작해도 OK, 반대(`이→리`)도 OK (`startsFor`)
- 저학년 배려: 사전에 없는 말도 첫 글자만 맞으면 받아 주고 격려, 두 글자 이상·중복만 걸러 냄. 말랑이는 이어 가기 쉬운 쉬운 말(그림 이모지 포함)로 대답, `도전` 단계는 어려운 끝 글자도 냄
- 말랑이가 이을 말이 없으면 아이의 승리
- 낱말: `index.html` 안 `kidWords`(쉬운 말 ~1,100개, 낱말 뒤 이모지) + `extra.txt`(보조 사전 약 5.2만 개: hunspell-ko 명사 어간 + 한자 사전의 흔한 한자어. `node build-extra.mjs` 로 생성, 출처 라이선스는 `source/LICENSE-hunspell-ko.txt`)
